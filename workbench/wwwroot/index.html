ANALYSIS QUALITY

The same Tracewright request may produce different results in different AI environments.

Model capability and version, custom instructions, prior chat context, context-window limits, and file-reading support can all change the depth and accuracy of the review.

For a cleaner comparison: use a new chat when possible, confirm that every file was read, record the model/version if known, and verify important Evidence Cards against the originals.
