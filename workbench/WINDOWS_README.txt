TRACEWRIGHT WORKBENCH 0.5.0 BETA
Narrative and automation-workflow review

START
Extract the complete ZIP. Open Tracewright Workbench.exe; keep wwwroot and schemas
beside it. Windows 10/11 x64. No separate .NET installation is needed.
Use Quit Workbench to stop the local process. Closing a tab does not stop it.
An occupied default port is replaced by an available loopback port.

REVIEW
Create a review or use Workflow intake. Importing the intake creates a local
review, not an AI assessment. Registered file names are not uploaded contents.
Add your permitted originals in Materials, then Inspect / prepare text.
TXT/MD/CSV/JSON/HTML/XML and DOCX/ODT body text can be prepared locally.
For PDF, legacy Office, RTF, images, tables or missing notes, paste a bounded
transcription/excerpt you have verified. Never treat empty text as a successful
file read. Originals remain unchanged and are not automatically sent.

DATA BOUNDARY
Before each dispatch, inspect the exact payload and select the sources.
In your own Codex or chosen AI, check the account/workspace, retention, training
use, organisation policy and permission to share. Tracewright cannot verify or
guarantee those terms. Do not enter passwords, tokens or API keys in TW.
The automatic connector requires a compatible Codex with ChatGPT sign-in.
It uses your Codex allowance and does not fall back to an API key.
It uses a fresh, ephemeral, read-only run with tools/custom configuration disabled.
Your existing conversation, preferred custom setup and memories are not the review.
The model runs through Codex, not offline. Approved content reaches that provider.
Manual transfer remains available for an AI service you choose and check yourself.

RESULTS AND ERRORS
Results must pass contract, source-role and exact-excerpt checks before replacing
the map. This checks structure and references, not correctness of the reasoning.
Prior results are preserved. Cancellation or timeout does not retract sent text.
No automatic retry occurs after failure or uncertain delivery. Use Run history to
inspect status and download a retained candidate for correction.

LOCAL STORAGE
%LOCALAPPDATA%\Tracewright\Workbench
This contains private originals, review text, approved payloads and run records.
Storage is not encrypted by Tracewright. Protect your Windows account and backups.
Removed materials are excluded from future requests but retained for history;
removal is NOT secure deletion. Back up the data folder before upgrading.
Never copy this data folder into the public repository or a distributable ZIP.

LIMITS
English UI. The installer may offer Japanese setup text, not a Japanese app.
This beta is unsigned: verify the release SHA-256 and source before running.
Not an AI detector, audit certification or decision authority. Qualified humans
remain responsible for high-impact decisions. Read LICENSE.txt and COMMERCIAL_USE.md.
