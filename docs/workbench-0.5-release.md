# Workbench 0.5.0 Beta

English Windows Workbench for narrative and automation-workflow review. The same release is used for public distribution and local desktop installation.

## Included

- Public fictional Review Lab and four-stage workflow intake packaged inside Workbench.
- Intake-to-local-review registration without pretending file metadata is uploaded content.
- Confirmed source text, explicit selection and exact-payload approval.
- User checks of Codex account/workspace, data-use terms and authority before each dispatch.
- Compatible ChatGPT-signed-in Codex connection, no API-key billing fallback.
- Automatic result return and manual approved-text bundle/result route.
- Workflow steps, conditional transitions, control observations, alternatives and next checks.
- Schema, source-role, literal-quote, stale-input and duplicate-dispatch checks.
- Cancellation, run status/history and preservation of previous maps and originals.
- Sensitive-review fields and older saved record compatibility retained.

## Verification And Limits

The development checks include contract and Unicode tests, missing consent, changed inputs, replay, invalid JSON, fabricated quotes, unknown sources, context-role preservation and local HTTP origin/token checks. A live test sent only a short fictional policy/event source through ChatGPT-signed-in Codex and verified a returned map with source-grounded excerpts. This does not establish analytical accuracy across documents or domains.

Public artifacts are built by GitHub Actions from the versioned checkout. Source and package allowlists exclude private projects, materials, payloads, logs, credentials, local caches and backups. Checksums accompany the portable ZIP and installer. Do not publish personal run logs in issues.

Before upgrading, back up `%LOCALAPPDATA%\Tracewright\Workbench`. Existing records and originals are not removed. The result contract for new runs differs from Starter Kit v0.6 and older manual bundles; use a fresh bundle from this version. Static browser downloads remain demo/intake tools, not automatic analysis clients.

Windows 10/11 x64; unsigned beta. English UI. No hosted document service. No direct API-key connector, existing-chat takeover, offline model, audit certification or automatic decision-making.

Text and DOCX/ODT body extraction require human verification. PDF/legacy formats and omitted material need a pasted verified transcription/excerpt. The connector sends bounded text only. Provider retention and training terms remain the user's responsibility to confirm, not an assertion made by the app.
